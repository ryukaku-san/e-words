# E-Words 📚 

Anthropicの公式エンジニアリングブログ記事『[How we contain Claude across products](https://www.anthropic.com/engineering/how-we-contain-claude)』から抽出した重要語彙・技術専門用語・熟語・構文を学ぶためのPWA（Progressive Web App）英語学習アプリです。

---

## 🌟 主な機能と特徴

1. **スマートフラッシュカード学習**
   - 英語を表示 → タップで回答・解説・例文・構文をオープン
   - 自己判定（「⭕ 覚えた」「❌ もう一度」）
   - **復習ループ機能**: 1周目で不正解だった問題だけを自動で集約し、もう1周（2周目）復習して定着！
2. **Web Speech API による英語ネイティブ音声読み上げ**
   - 追加料金や外部API契約不要、ブラウザ標準機能による完全無料のネイティブ発音再生（単語・例文）。
3. **3つのUIテーマをリアルタイム切り替え**
   - ☀️ **シンプル (Simple)**: 清潔感のある白・スレートグレー。集中力を高めるミニマルデザイン。
   - 🌙 **ダーク (Dark)**: 漆黒とネオンシアン。夜間学習でも目に優しくスタイリッシュなテック感。
   - 🎨 **ポップ (Pop)**: Duolingo風の親しみやすいウォームイエローと立体的な押し込みボタン。
4. **学習カレンダー & ストリーク（連続日数）記録**
   - 学習を完了した日付には自動で「丸（スタンプ）」が付きます。
   - 日付をタップすると、その日に解いた問題数・正答率・学習カテゴリの内訳を確認できます。
   - 連続学習日数（🔥 ストリーク）カウントでモチベーションを維持。
5. **カテゴリ別学習 & 単語辞書一覧**
   - 重要語彙（39語）
   - AI・セキュリティ技術専門用語（13語）
   - 熟語・句動詞（20語）
   - 英文法・構文（10構文）
   - 全文検索・お気に入り（苦手単語帳）機能
6. **完全無料の静的PWA設計**
   - バックエンド不要（LocalStorageで端末内に学習データを安全に保存）。
   - オフライン動作対応（Service Worker）。
   - スマホのホーム画面に追加してネイティブアプリ感覚で利用可能。

## 🚀 GitHub Pages への公開手順（完全無料）

本リポジトリには、GitHub Actions による自動デプロイワークフロー（`.github/workflows/deploy.yml`）があらかじめ設定されています。

### 手順（1分で完了）
1. GitHub で新しい空のリポジトリ（例: `e-words`）を作成します。
2. ローカルのコードをリモートリポジトリへ push します:
   ```bash
   git remote add origin https://github.com/<あなたのユーザー名>/e-words.git
   git branch -M main
   git push -u origin main
   ```
3. GitHubリポジトリのページで **[Settings]** → **[Pages]** を開きます。
4. **[Build and deployment]** の **Source** を **`GitHub Actions`** に変更します。
5. push を契機にワークフローが自動で実行され、数分で `https://<あなたのユーザー名>.github.io/e-words/` にアプリが公開されます！

## 🛠 ローカル開発

```bash
# 依存パッケージのインストール
npm install

# 開発サーバー起動
npm run dev

# プロダクションビルド（型チェック + Viteビルド + PWA生成）
npm run build
```
